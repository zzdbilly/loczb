使用 Kotlin Symbol Processing 提升编译效率

📅 2026-06-28 ⏱️ 8 min read 👤 张小猛
Kotlin KSP 编译优化 Android

Kotlin Symbol Processing（KSP）是 Kotlin 官方推出的全新编译时注解处理方案，旨在替代传统的 KAPT（Kotlin Annotation Processing Tool）。相比 KAPT，KSP 在编译速度上有 2-10 倍的显著提升。

为什么需要 KSP？

KAPT 虽好，但它有几个固有问题：

  • 性能问题：KAPT 需要将 Kotlin 代码转换为 Java 代理类，这一步骤耗时较长
  • 信息丢失：KAPT 只保留最少的 Kotlin 语言特性，很多运行时信息被丢弃
  • 增量编译不完善：增量编译支持有限

从 KAPT 迁移到 KSP

1. 添加 KSP 插件

plugins {
    id("com.google.devtools.ksp") version "1.9.22-1.0.17"
}

2. 替换依赖配置

// 之前 (KAPT)
implementation("com.squareup.moshi:moshi-kotlin:1.15.0")
kapt("com.squareup.moshi:moshi-kotlin-codegen:1.15.0")

// 现在 (KSP)
implementation("com.squareup.moshi:moshi-kotlin:1.15.0")
ksp("com.squareup.moshi:moshi-kotlin-codegen:1.15.0")

支持的库

主流 Kotlin 库都已支持 KSP：

  • Room
  • Moshi
  • Hilt（新版）
  • SQLDelight
  • Kotlin Serialization
  • Google Auto Service

总结

KSP 是 Kotlin 生态的重要进步，推荐在新项目中直接使用。对于现有项目，建议逐步迁移到 KSP 以获得更好的编译体验。
