Android 离线语音输入实现方案

2026年4月3日 · 阅读时间 12 分钟

在移动应用中集成语音输入功能时，网络依赖往往成为最大的痛点。弱网环境、隐私敏感场景、实时性要求高的应用，都需要离线语音识别方案。

主流方案对比

方案模型大小准确率中文支持推荐指数
Vosk50MB-1GB高优秀5/5
Whisper39MB-155MB很高优秀4/5
PocketSphinx25MB-100MB中等一般3/5
Google Speech内置高优秀4/5

Vosk 集成实战

1. 添加依赖

dependencies {
    implementation 'com.alphacephei:vosk-android:0.3.47'
}

2. 核心代码

class VoskRecognizer(context: Context) {
    private val modelPath = File(context.filesDir, "vosk-model").absolutePath
    private var model: Model? = null
    
    fun init() {
        model = Model(modelPath)
    }

性能优化建议

  • 小型模型(40MB)适合实时场景
  • 中型模型(120MB)平衡准确率和性能
  • 后台Service执行长时间识别
