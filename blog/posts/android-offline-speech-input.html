Android 离线语音输入实现方案

2026年4月3日 · 阅读时间 25 分钟

在移动应用开发中，语音输入已成为提升用户体验的重要交互方式。然而，传统的云端语音识别方案存在明显的痛点：网络依赖、隐私风险、延迟抖动、成本不可控。对于需要高隐私保护、弱网环境可用、或实时性要求高的场景，真正的离线语音识别成为必需。

本文将深入对比 Android 平台三大主流离线语音识别方案：Sherpa ONNX（新一代高性能方案）、Whisper（OpenAI 开源模型）、Vosk（成熟的 Kaldi 方案），并提供完整的 Kotlin 集成代码和性能优化建议。

为什么必须选择真正的离线方案？

在讨论具体方案前，有必要澄清一个常见误区：Google SpeechRecognizer 的"离线模式"并非真正的离线方案。它仍然依赖系统预装的语音包，且可控性差、无法自定义模型、隐私保护有限。

⚠️ 注意：本文讨论的"离线语音识别"指的是完全端侧运行的方案，模型文件打包在 APK 中或下载到本地，识别过程不依赖任何网络请求。

离线语音识别的核心价值

  • 零网络依赖：地下室、飞机、偏远地区、弱网环境完全可用
  • 隐私绝对保护：语音数据永不上传，满足医疗、金融等敏感场景合规要求
  • 超低延迟：端到端延迟通常 < 200ms，云端方案通常 500ms-2s
  • 零运营成本：无 API 调用费用，适合高频使用场景
  • 完全可控：可自定义模型、热词、领域词汇，不受第三方服务限制

方案详解

1. Sherpa ONNX（强烈推荐）

Sherpa ONNX 是新一代开源语音识别工具包，基于下一代 Kaldi（k2）和 ONNX Runtime，专为嵌入式和移动设备优化。

✅ 核心优势：
  • 支持多种模型架构（Transducer、CTC、Paraformer）
  • 模型体积小巧，量化后仅 30MB 即可达到商用级准确率
  • 支持流式识别，延迟极低
  • 中文模型效果优异，支持方言
  • 活跃的社区维护，持续更新

2. Whisper（OpenAI）

OpenAI 开源的通用语音识别模型，以大模型思路实现多语言语音识别。需要通过 whisper.cpp 或 faster-whisper 移植到移动端。

适用场景：对准确率要求极高、可接受一定延迟、需要多语言支持的离线场景。不适合实时流式识别。

3. Vosk

基于传统 Kaldi 的轻量级语音识别工具包，API 设计简洁，适合快速集成。但模型相对老旧，Sherpa ONNX 正在逐步替代 Vosk 成为更好的选择。

Sherpa ONNX 集成实战

下面提供完整的 Sherpa ONNX Android 集成代码，包含模型准备、录音、流式识别、结果回调全流程。

1. 准备工作

下载模型

从 Sherpa ONNX Releases 下载预训练模型。推荐以下中文模型：

  • sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23：14MB，适合资源受限设备
  • sherpa-onnx-streaming-zipformer-zh-20M-2023-02-23：20MB，平衡性能和准确率
  • sherpa-onnx-paraformer-zh-2023-03-28：Paraformer 架构，非流式但准确率更高

3. 核心识别类

import android.content.Context
import android.media.AudioFormat
import android.media.AudioRecord
import android.media.MediaRecorder
import com.k2fsa.sherpa.onnx.OfflineRecognizer
import com.k2fsa.sherpa.onnx.OfflineRecognizerConfig
import com.k2fsa.sherpa.onnx.OfflineModelConfig
import com.k2fsa.sherpa.onnx.OfflineParaformerModelConfig
import com.k2fsa.sherpa.onnx.OfflineTransducerModelConfig
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*
import java.io.File
import java.io.FileOutputStream

/**
 * Sherpa ONNX 离线语音识别器
 * 
 * 支持两种模式：
 * 1. 流式识别（Streaming）：适合实时语音输入，延迟低
 * 2. 非流式识别（Offline）：适合短音频文件，准确率更高
 */
class SherpaOnnxRecognizer(private val context: Context) {
    
    companion object {
        const val SAMPLE_RATE = 16000
        const val BUFFER_SIZE = 1600  // 100ms @ 16kHz
    }
    
    // 模型路径
    private val modelDir by lazy { 
        File(context.filesDir, "sherpa-onnx-model").absolutePath 
    }
    
    // 识别器实例
    private var recognizer: OfflineRecognizer? = null
    
    // 录音相关
    private var audioRecord: AudioRecord? = null
    private var recordingJob: Job? = null
    
    // 状态管理
    private val _state = MutableStateFlow(RecognitionState.Idle)
    val state: StateFlow = _state.asStateFlow()
    
    private val _partialResult = MutableStateFlow("")
    val partialResult: StateFlow = _partialResult.asStateFlow()
    
    private val _finalResult = MutableStateFlow("")
    val finalResult: StateFlow = _finalResult.asStateFlow()
    
    /**
     * 初始化：复制模型到本地并创建识别器
     */
    suspend fun initialize(modelType: ModelType = ModelType.ZIPFORMER_20M) = withContext(Dispatchers.IO) {
        try {
            _state.value = RecognitionState.Initializing
            
            // 首次运行：从 assets 复制模型
            if (!File(modelDir).exists()) {
                copyModelFromAssets(modelType.assetPath)
            }
            
            // 创建识别器配置
            val config = createRecognizerConfig(modelType)
            recognizer = OfflineRecognizer(config)
            
            _state.value = RecognitionState.Ready
        } catch (e: Exception) {
            _state.value = RecognitionState.Error("初始化失败: ${e.message}")
        }
    }
    
    /**
     * 从 Assets 复制模型文件
     */
    private fun copyModelFromAssets(assetPath: String) {
        val destDir = File(modelDir)
        destDir.mkdirs()
        
        context.assets.list(assetPath)?.forEach { fileName ->
            val input = context.assets.open("$assetPath/$fileName")
            val output = FileOutputStream(File(destDir, fileName))
            input.copyTo(output)
            input.close()
            output.close()
        }
    }
    
    /**
     * 创建识别器配置
     */
    private fun createRecognizerConfig(type: ModelType): OfflineRecognizerConfig {
        return when (type) {
            ModelType.ZIPFORMER_14M, ModelType.ZIPFORMER_20M -> {
                // Transducer 模型配置（流式）
                val modelConfig = OfflineModelConfig().apply {
                    transducer = OfflineTransducerModelConfig().apply {
                        encoder = "$modelDir/encoder.onnx"
                        decoder = "$modelDir/decoder.onnx"
                        joiner = "$modelDir/joiner.onnx"
                    }
                    tokens = "$modelDir/tokens.txt"
                    numThreads = 4
                    debug = false
                }
                OfflineRecognizerConfig().apply {
                    modelConfig = modelConfig
                }
            }
            
            ModelType.PARAFORMER -> {
                // Paraformer 模型配置（非流式，准确率更高）
                val modelConfig = OfflineModelConfig().apply {
                    paraformer = OfflineParaformerModelConfig().apply {
                        model = "$modelDir/model.onnx"
                    }
                    tokens = "$modelDir/tokens.txt"
                    numThreads = 4
                }
                OfflineRecognizerConfig().apply {
                    modelConfig = modelConfig
                }
            }
        }
    }
    
    /**
     * 开始实时录音识别
     */
    fun startListening() {
        if (recognizer == null) {
            _state.value = RecognitionState.Error("识别器未初始化")
            return
        }
        
        // 初始化 AudioRecord
        val minBufferSize = AudioRecord.getMinBufferSize(
            SAMPLE_RATE,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT
        )
        
        audioRecord = AudioRecord(
            MediaRecorder.AudioSource.MIC,
            SAMPLE_RATE,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT,
            minBufferSize
        )
        
        audioRecord?.startRecording()
        _state.value = RecognitionState.Listening
        
        // 启动录音协程
        recordingJob = CoroutineScope(Dispatchers.IO).launch {
            val buffer = ShortArray(BUFFER_SIZE)
            val samples = mutableListOf()
            
            while (isActive && audioRecord?.recordingState == AudioRecord.RECORDSTATE_RECORDING) {
                val read = audioRecord?.read(buffer, 0, BUFFER_SIZE) ?: 0
                if (read > 0) {
                    // 转换为 float 样本
                    for (i in 0 until read) {
                        samples.add(buffer[i] / 32768.0f)
                    }
                    
                    // 每 1 秒进行一次识别
                    if (samples.size >= SAMPLE_RATE) {
                        val audioData = samples.toFloatArray()
                        samples.clear()
                        
                        val result = recognizer?.decode(audioData, SAMPLE_RATE)
                        result?.let {
                            _partialResult.value = it.text
                        }
                    }
                }
            }
        }
    }
    
    /**
     * 停止录音并获取最终结果
     */
    fun stopListening() {
        recordingJob?.cancel()
        recordingJob = null
        
        audioRecord?.apply {
            stop()
            release()
        }
        audioRecord = null
        
        _state.value = RecognitionState.Idle
    }
    
    /**
     * 识别音频文件（非实时）
     */
    suspend fun recognizeFile(audioFile: File): String = withContext(Dispatchers.IO) {
        val audioData = readAudioFile(audioFile)
        val result = recognizer?.decode(audioData, SAMPLE_RATE)
        result?.text ?: ""
    }
    
    /**
     * 读取音频文件（假设为 16kHz 16bit PCM）
     */
    private fun readAudioFile(file: File): FloatArray {
        val bytes = file.readBytes()
        val shorts = ShortArray(bytes.size / 2)
        
        // 小端序转换
        for (i in shorts.indices) {
            shorts[i] = ((bytes[i * 2 + 1].toInt() shl 8) or 
                        (bytes[i * 2].toInt() and 0xFF)).toShort()
        }
        
        return shorts.map { it / 32768.0f }.toFloatArray()
    }
    
    /**
     * 释放资源
     */
    fun release() {
        stopListening()
        recognizer?.release()
        recognizer = null
    }
    
    /**
     * 支持的模型类型
     */
    enum class ModelType(val assetPath: String) {
        ZIPFORMER_14M("sherpa-onnx-model-14m"),
        ZIPFORMER_20M("sherpa-onnx-model-20m"),
        PARAFORMER("sherpa-onnx-paraformer")
    }
    
    /**
     * 识别状态
     */
    sealed class RecognitionState {
        object Idle : RecognitionState()
        object Initializing : RecognitionState()
        object Ready : RecognitionState()
        object Listening : RecognitionState()
        data class Error(val message: String) : RecognitionState()
    }
}

4. Jetpack Compose UI 组件

@Composable
fun VoiceInputScreen(
    modifier: Modifier = Modifier
) {
    val context = LocalContext.current
    val recognizer = remember { SherpaOnnxRecognizer(context) }
    
    val state by recognizer.state.collectAsState()
    val partialText by recognizer.partialResult.collectAsState()
    var finalText by remember { mutableStateOf("") }
    
    // 权限申请
    val recordPermission = rememberPermissionState(
        permission = Manifest.permission.RECORD_AUDIO
    )
    
    // 初始化识别器
    LaunchedEffect(Unit) {
        recognizer.initialize(SherpaOnnxRecognizer.ModelType.ZIPFORMER_20M)
    }
    
    // 清理资源
    DisposableEffect(Unit) {
        onDispose { recognizer.release() }
    }
    
    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        // 状态显示
        when (state) {
            is SherpaOnnxRecognizer.RecognitionState.Initializing -> {
                CircularProgressIndicator()
                Text("正在加载模型...", modifier = Modifier.padding(top = 8.dp))
            }
            is SherpaOnnxRecognizer.RecognitionState.Error -> {
                Text(
                    text = (state as SherpaOnnxRecognizer.RecognitionState.Error).message,
                    color = MaterialTheme.colorScheme.error
                )
            }
            else -> {
                // 识别结果显示
                Card(
                    modifier = Modifier
                        .fillMaxWidth()
                        .weight(1f)
                        .padding(bottom = 16.dp)
                ) {
                    Column(modifier = Modifier.padding(16.dp)) {
                        Text(
                            text = "识别结果",
                            style = MaterialTheme.typography.titleMedium
                        )
                        
                        // 实时部分结果
                        if (partialText.isNotEmpty()) {
                            Text(
                                text = partialText,
                                style = MaterialTheme.typography.bodyLarge,
                                color = MaterialTheme.colorScheme.primary,
                                modifier = Modifier.padding(top = 8.dp)
                            )
                        }
                        
                        // 最终结果
                        if (finalText.isNotEmpty()) {
                            Text(
                                text = finalText,
                                style = MaterialTheme.typography.bodyLarge,
                                modifier = Modifier.padding(top = 8.dp)
                            )
                        }
                    }
                }
                
                // 录音按钮
                FloatingActionButton(
                    onClick = {
                        when (state) {
                            is SherpaOnnxRecognizer.RecognitionState.Listening -> {
                                recognizer.stopListening()
                                finalText = partialText
                            }
                            is SherpaOnnxRecognizer.RecognitionState.Ready -> {
                                if (recordPermission.status.isGranted) {
                                    recognizer.startListening()
                                } else {
                                    recordPermission.launchPermissionRequest()
                                }
                            }
                            else -> {}
                        }
                    },
                    containerColor = when (state) {
                        is SherpaOnnxRecognizer.RecognitionState.Listening -> 
                            MaterialTheme.colorScheme.error
                        else -> MaterialTheme.colorScheme.primary
                    }
                ) {
                    Icon(
                        imageVector = if (state is SherpaOnnxRecognizer.RecognitionState.Listening) {
                            Icons.Default.Stop
                        } else {
                            Icons.Default.Mic
                        },
                        contentDescription = "语音输入"
                    )
                }
            }
        }
    }
}

Whisper 集成方案

Whisper 更适合非实时场景，如语音转写、会议记录等。这里介绍使用 faster-whisper 的 Android 移植方案。

1. 使用 whisper.cpp

whisper.cpp 是 Whisper 的 C++ 实现，通过 JNI 可以在 Android 中使用。

// build.gradle
android {
    externalNativeBuild {
        cmake {
            path "src/main/cpp/CMakeLists.txt"
        }
    }
}

dependencies {
    // 或使用预编译的 AAR
    implementation 'com.github.ggerganov:whisper-cpp-android:1.5.0'
}

2. Kotlin 封装

class WhisperRecognizer(context: Context) {
    
    private val modelPath: String
    
    init {
        // 复制模型到本地
        val modelFile = File(context.filesDir, "whisper-model/ggml-base.bin")
        if (!modelFile.exists()) {
            copyModelFromAssets(context, "whisper-model/ggml-base.bin", modelFile)
        }
        modelPath = modelFile.absolutePath
        
        // 加载 native 库
        System.loadLibrary("whisper")
    }
    
    /**
     * 识别音频文件
     * 注意：Whisper 需要完整的音频文件，不适合流式识别
     */
    fun transcribe(audioFile: File, language: String = "zh"): String {
        return whisperFull(modelPath, audioFile.absolutePath, language)
    }
    
    // Native 方法声明
    private external fun whisperFull(
        modelPath: String, 
        audioPath: String, 
        language: String
    ): String
}
⚠️ Whisper 的局限：
  • 不支持真正的流式识别，需要完整音频文件
  • 延迟较高，不适合实时语音输入
  • 模型加载内存占用大

Vosk 集成方案（备选）

Vosk 是较早的离线语音识别方案，API 设计简洁，适合快速原型开发。

class VoskRecognizer(context: Context) {
    private val model = Model("${context.filesDir}/vosk-model")
    private var recognizer: Recognizer? = null
    
    fun startListening(callback: (String) -> Unit) {
        recognizer = Recognizer(model, 16000f)
        
        // 使用 SpeechService 简化录音流程
        val service = SpeechService(recognizer, 16000f)
        service.startListening(object : RecognitionListener {
            override fun onPartialResult(hypothesis: String?) {
                // 实时部分结果
            }
            override fun onResult(hypothesis: String?) {
                callback?.invoke(JSONObject(hypothesis).getString("text"))
            }
            override fun onFinalResult(hypothesis: String?) {}
            override fun onError(exception: Exception?) {}
            override fun onTimeout() {}
        })
    }
}

性能优化与最佳实践

1. 模型选择策略

场景推荐模型模型大小RTF
实时语音输入Sherpa ONNX Zipformer 20M~60MB0.1
低功耗设备Sherpa ONNX Zipformer 14M~40MB0.05
高准确率要求Sherpa ONNX Paraformer~200MB0.3
多语言支持Whisper Base~150MB1.0+

RTF (Real-Time Factor)：处理 1 秒音频所需的时间，< 1 表示实时

2. 内存优化

  • 延迟加载：首次使用时再加载模型，避免启动慢
  • 模型缓存：识别器实例复用，避免重复加载
  • 后台识别：长时间识别使用 Service，避免 Activity 销毁
  • 量化模型：使用 INT8 量化模型，内存占用减少 50%

3. 热词优化

Sherpa ONNX 支持热词（Hotwords）提升特定词汇识别率：

// 在配置中添加热词
val config = OfflineRecognizerConfig().apply {
    modelConfig = modelConfig
    // 提升特定领域词汇识别率
    hotwordsFile = "$modelDir/hotwords.txt"
    hotwordsScore = 20.0f  // 热词权重
}

4. 音频预处理

/**
 * 音频预处理：降噪、VAD、归一化
 */
fun preprocessAudio(samples: FloatArray): FloatArray {
    // 1. 语音活动检测 (VAD) - 过滤静音
    val vad = WebRtcVad()
    vad.setMode(AGGRESSIVE_MODE)
    
    // 2. 降噪
    val ns = NoiseSuppressor.create(SAMPLE_RATE, 1)
    ns.process(samples)
    
    // 3. 音量归一化
    val max = samples.maxOf { kotlin.math.abs(it) }
    return if (max > 0) samples.map { it / max * 0.95f }.toFloatArray() else samples
}

常见问题

Q: 模型文件太大，如何减小 APK 体积？

A: 三种方案：

  1. 使用 App Bundle 分包，只打包对应架构的 so 文件
  2. 首次启动时从服务器下载模型（推荐）
  3. 使用更小的模型（如 Sherpa ONNX 14M 版本）

Q: 识别准确率不理想怎么办？

A: 检查以下几点：

  • 录音采样率是否为 16kHz（这是模型训练的标准）
  • 环境噪音是否过大（建议添加降噪处理）
  • 是否使用了热词文件提升领域词汇识别率
  • 尝试更大的模型（准确率 vs 性能权衡）

Q: 支持方言识别吗？

A: Sherpa ONNX 的中文模型对普通话支持最好，部分方言（粤语、四川话）有一定支持但准确率下降。如需特定方言，需要自行训练模型或使用云端方案。

Q: 可以自定义训练模型吗？

A: 可以。Sherpa ONNX 基于 ESPnet 和 Kaldi，支持使用自己的数据微调模型。需要准备音频数据集和对应的文本标注，训练流程参考官方文档。

总结

Android 离线语音识别技术已经相当成熟，Sherpa ONNX 凭借出色的性能、小巧的模型体积和活跃的社区，成为当前最推荐的方案。

方案推荐场景注意事项
Sherpa ONNX实时语音输入、低延迟场景首选方案，中文效果优异
