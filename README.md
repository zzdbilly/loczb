# loczb 2.0

> 张小猛的个人主页 - 极简主义 + 精致细节

## 🎨 设计特点

- **极简主义设计** - 干净利落的视觉风格
- **暗色主题** - 舒适的深色背景 + 蓝紫强调色
- **独特字体** - JetBrains Mono + Noto Serif SC + Plus Jakarta Sans
- **流畅动效** - 页面加载动画、滚动触发动画、精致的微交互
- **响应式布局** - 完美适配桌面端和移动端

## 🚀 技术栈

- **纯 HTML/CSS/JS** - 无框架依赖，轻量快速
- **CSS 变量** - 灵活的主题管理系统
- **CSS Grid & Flexbox** - 现代化布局
- **Intersection Observer** - 性能优化的滚动动画
- **Google Fonts** - 精选字体组合
