PasteBin

轻量文本分享工具 — 贴文本，一键生成链接分享

项目背景

需要一个极简的文本分享工具，贴代码、日志、配置片段，快速生成链接发给别人。不需要注册登录，用完即走。对标 Pastebin.com，但更轻量、免费。

我的角色

全栈独立开发 — 从需求、架构设计、前端到后端逻辑，全流程搞定。

技术方案

Cloudflare Workers KV highlight.js Web Crypto API

功能特性

• 一键创建粘贴，生成 6 位短码链接
• 过期时间：1小时 / 24小时 / 7天
• 阅后即焚：打开一次自动删除
• 密码保护：SHA-256 加密 + Token 验证
• 语法高亮：自动检测 22 种语言
• Raw 模式：纯文本输出
• 所有页面暗色主题，移动端适配
